# Issue 118 피격 시 파티클 및 데미지 숫자 표시 계획

> GitHub Issue: [FEAT] 피격 시 파티클 및 데미지 숫자 표시
> 작업 브랜치: `feature/118-hit-damage-feedback`

---

## 목표

캐릭터가 실제 HP 피해를 받을 때 피격 파티클을 재생하고, 피해량을 캐릭터 머리 위에 숫자로 표시한다.

---

## 구현 방향

- 플레이어와 적이 함께 사용하는 `CharacterBase.GetDamage(int amount)`에서 방어도 적용 후 실제 HP 감소량을 계산한다.
- 실제 HP 피해량이 1 이상이면 공통 피격 피드백을 호출한다.
- `HitFeedbackView`가 캐릭터별 피격 앵커, 피격 파티클, 데미지 숫자 프리팹 생성을 담당한다.
- `DamageNumberView`가 TMP 숫자 표시, 상승 이동, 페이드아웃, 자동 제거를 담당한다.
- 피격 파티클은 외부 이미지 없이 Unity 기본 `ParticleSystem` 프리팹으로 제작한다.
- 플레이어와 적 프리팹에 피격 앵커와 `HitFeedbackView`를 연결한다.

---

## 완료 기준

- 플레이어가 데미지를 받을 때 피격 파티클과 데미지 숫자가 표시된다.
- 적이 데미지를 받을 때 피격 파티클과 데미지 숫자가 표시된다.
- 방어도 적용 후 실제 HP에 들어간 데미지 기준으로 숫자가 표시된다.
- 방어도로 전부 막힌 경우 데미지 숫자는 표시되지 않고 기존 Hit 애니메이션은 유지된다.
- 연속 공격 카드 사용 시 각 타격의 숫자가 약간 분산되어 읽을 수 있다.
- 사망 타격 후 기존 사망 애니메이션, 적 제거, 전투 종료 흐름이 유지된다.

---

## 제외 범위

- 새 이미지, 사운드, 폰트 원본 파일 추가
- 카메라 흔들림
- 공격자 이동 연출
- 피격 사운드
