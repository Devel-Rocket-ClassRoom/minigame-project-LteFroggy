# Break The King 빌드 0.4.0 계획

## 빌드 0.3.0 회고

빌드 0.3.0에서는 카드/유물 확장, 툴팁, 피격 피드백, 보물상자 노드, 엔딩 흐름 등 플레이 완성도를 높이는 주요 이슈가 다수 종료되었습니다.

다만 열린 `bug` 이슈와 PC 빌드 추출 이슈가 남아 있어, 다음 빌드는 **버그 안정화 + 최종 빌드 추출 + UI/밸런스 정리**에 집중합니다.
