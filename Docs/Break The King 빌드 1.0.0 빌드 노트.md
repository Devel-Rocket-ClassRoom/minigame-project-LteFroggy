## 이 빌드의 목표

빌드 1.0.0은 발표 및 최종 제출을 위한 PC 빌드 후보입니다.

0.3.0 이후 남아 있던 주요 UI/UX 문제, 카드/상태이상 미리보기, 일반 적 다양화, 일시정지/메인 복귀, 맵 가독성, 카드 사용 입력 안정성 등을 정리해 플레이 가능한 최종 형태로 묶는 것을 목표로 합니다.

이번 문서는 GitHub 이슈 상태와 로컬 빌드 산출물 확인 결과를 기준으로 작성했습니다.

## 0.3.0 대비 주요 변화 요약

- 시작 덱 선택, 에너지 부족 안내, 공명 카드 사용 제한 안내 등 사용 실패 사유를 더 명확하게 보여줍니다.
- 일반 적과 스폰 테이블이 확장되어 전투 반복감이 줄었습니다.
- 설명 패널, 상태 아이콘, 키워드 색상, HUD 버튼 등 UI 가독성 문제가 다수 수정되었습니다.
- 일시정지 패널과 메인 화면 복귀 흐름이 추가되어 발표/시연 중 조작 안정성이 좋아졌습니다.
- 1.0.0 PC 빌드 산출물이 생성되어 있습니다.

## 플레이에 필요한 정보

### 조작 방법

| 조작 | 방법 |
|---|---|
| 메뉴 선택 | 마우스로 버튼 클릭 |
| 일시정지 | `ESC` 또는 HUD 일시정지 버튼 |
| 로드아웃 선택 | 유물 선택 후 시작 카드 선택 |
| 카드 사용 | 카드를 마우스로 드래그해 적 위에 드롭 |
| 턴 종료 | 화면 우측 턴 종료 버튼 클릭 |
| 카드 / 유물 / 상태이상 설명 확인 | 대상에 마우스 호버 |
| 덱 확인 | HUD 덱 버튼 클릭 |
| 맵 확인 | HUD 맵 버튼 클릭 |

### 플레이 흐름

1. `MainScene`에서 게임 시작
2. 로드아웃에서 유물 및 시작 카드 선택
3. `StartScene` 진입 후 맵으로 이동
4. 맵에서 전투 / 휴식 / 이벤트 / 보물상자 노드 진행
5. 마지막 레이어의 보스 노드 진입
6. 보스 처치 후 엔딩 씬으로 이동
